Sobre el proyecto

Help Desk PWA

Sistema web progresivo diseñado para facilitar el registro, consulta y seguimiento de solicitudes de soporte técnico desde computadores, tabletas y dispositivos móviles.

¿Qué es Help Desk?

Help Desk es una aplicación web progresiva orientada a la gestión de incidentes y solicitudes de soporte técnico. Su objetivo es proporcionar un punto centralizado donde los usuarios puedan registrar problemas, consultar el estado de sus solicitudes y hacer seguimiento al proceso de atención.

Objetivo del sistema

Mejorar la gestión de soporte técnico mediante una plataforma accesible, organizada y fácil de usar que permita registrar incidentes, clasificarlos, establecer prioridades y realizar seguimiento durante todo su ciclo de atención.

Funcionalidades principales

El MVP del sistema contempla las siguientes capacidades.

Registro de tickets Creación de solicitudes de soporte técnico.
Consulta Visualización de tickets registrados.
Búsqueda Localización de tickets mediante ID, usuario o asunto.
Filtros Filtrado por estado y prioridad.
Seguimiento Consulta detallada del progreso de cada solicitud.
Gestión de estados Abierto, en proceso, resuelto y cerrado.

Ciclo de atención del ticket

Cada solicitud puede avanzar por diferentes estados según el trabajo realizado por soporte.

Abierto El ticket fue registrado y está pendiente de revisión.
En proceso El equipo de soporte está trabajando en la solicitud.
Resuelto Se aplicó una solución al incidente reportado.
Cerrado La solicitud finalizó su ciclo de atención.

¿Por qué es una PWA?

El sistema está diseñado bajo el enfoque Progressive Web App (PWA). Esto permitirá que la aplicación pueda instalarse desde un navegador compatible, adaptarse a diferentes tamaños de pantalla y disponer de recursos almacenados en caché para mejorar la experiencia en condiciones de conectividad limitada.

Beneficios de la solución

Responsive Adaptación a computador, tableta y celular.
Instalable Posibilidad de instalar la aplicación desde el navegador.
Acceso rápido Disponible mediante navegador sin necesidad de una tienda de aplicaciones.
Caché Recursos esenciales disponibles incluso ante problemas de conectividad.
Actualización Los cambios pueden distribuirse directamente desde el servidor.
Multiplataforma Compatible con diferentes sistemas operativos y navegadores.

Tecnologías utilizadas

HTML5 Estructura semántica de las interfaces.
CSS3 Diseño visual y comportamiento responsive.
JavaScript Lógica y comportamiento dinámico de la aplicación.
LocalStorage Persistencia local temporal de tickets.
Web App Manifest Información necesaria para instalar la PWA.
Service Worker Gestión de caché y funcionamiento offline.

Arquitectura actual del prototipo

Esta primera versión funciona principalmente en el lado del cliente. Los tickets son almacenados en el LocalStorage del navegador, permitiendo demostrar el flujo funcional del MVP sin depender todavía de un servidor o una base de datos externa. En una fase posterior, esta arquitectura puede evolucionar hacia una API REST, autenticación de usuarios y una base de datos centralizada.
